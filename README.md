# 植物增强计划 Plants Enhancement Program (PEP)

PvZ2 Gardendless 增强模组「植物增强计划 PEP」的预览版发布仓库。

- 官方网站：https://pvzge.com/
- 预览版站点（下载入口）：本仓库的 `index.html`
- 作者反馈/B站：https://space.bilibili.com/518811104


## 下载与安装

见仓库根目录的 `index.html`（或直接下载 `downloads/` 下的压缩包）：

1. 下载并解压压缩包；
2. 把解压出的模组文件夹放入游戏的 `gp-next/packs/` 目录；
3. 启动游戏，在 GP-Next 侧边栏「模组」页确认已激活。

当前为**预览版 v1.0**：三线大哥融合暂未开放，其余功能均可正常体验。

## 仓库结构

```
├── index.html            # 预览版下载页
├── downloads/            # 发布用压缩包（PEP / 血量显示）
└── (模组源码目录)         
```
